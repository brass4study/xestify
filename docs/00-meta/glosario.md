# Glosario de términos Xestify (borrador)

- **Entidad**: Objeto de negocio configurable (ej. Cliente, Producto).
- **Plugin**: Módulo que añade o modifica funcionalidad, puede ser entidad o extensión.
- **Extensión**: Plugin que amplía una entidad base (ej. Optometría para Cliente).
- **Hook**: Punto de enganche para lógica personalizada.
- **Edge computing**: Procesamiento local en el dispositivo del negocio (RPi5).
- **Multi-inquilino**: Varios negocios en una sola instancia (no aplicable aquí).
- **Microkernel**: Núcleo mínimo, todo lo demás son plugins.
- **JSONB**: Tipo de dato flexible en PostgreSQL para almacenar datos variables.
