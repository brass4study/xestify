# Convenciones y glosario (borrador)

Este archivo debe recoger las convenciones técnicas, de nomenclatura y de contribución para el proyecto Xestify, así como un glosario de términos clave.

- Nombres técnicos en inglés para claves, español para documentación visible
- Estructura de carpetas numerada por flujo de lectura
- Plugins y entidades: definición y diferencias
- Multi-inquilino vs. instalación local
- Edge computing, RPi5, microkernel
